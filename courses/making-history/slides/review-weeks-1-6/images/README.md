# Slide Images — Every Historian Picks a Scale (review of Weeks 1–6)

Four images used by `../index.md`, **all copied from the decks this one
reviews**, all public domain. They are byte-for-byte copies of the files in the
decks named below; if one is re-cropped or replaced there, copy it here again.
If you change a filename, update the matching `data-background-image` in
`../index.md`.

Each one is full-bleed at the head of a writer's slide in Weeks 5–6, and each is
the image that week was built on: the mill nobody voted for, the hillside that
outlasts the battle, the cropper in a dress, the room with no women in it. They
replaced the four portraits this deck used to open those weeks with — see
`../ISSUES.md`.

Nothing here is new to the students. That is the point: each image is one they
have already sat with, so a review can put it up cold and ask the room what it
was for. Don't swap one for a fresh picture of the same subject — a picture
they have never seen is a new argument to introduce, not a cue to recall.
