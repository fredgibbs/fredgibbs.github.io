## Processing

Every file was resized with `sips -Z <long edge> -s formatOptions <q>`; crops
were made with `sips -c <h> <w> --cropOffset <y> <x>` before resizing, with
the long edge set no larger than the crop so nothing was upscaled. The Library
of Congress master TIFFs are at
`https://tile.loc.gov/storage-services/master/pnp/<collection>/<path>/<id>u.tif`;
the item page (`https://www.loc.gov/item/<lccn>/`) links each one. Commons
files re-fetch with
`curl -L 'https://commons.wikimedia.org/wiki/Special:FilePath/<FILE>?width=<W>'`.

## Notes

**Substitutions.** Wikimedia Commons rate-limited the downloads partway
through, so three planned images were replaced with Library of Congress
equivalents: the 1629 Massachusetts Bay Colony seal (an Indian saying "Come
over and help us") became the Pequot fort engraving; the 1823 *Ten Views in
the Island of Antigua* cane-cutting plate became the Du Tertre sugar works;
and a 1921 newspaper photograph of Yezierska became the 1925 Underwood
portrait. The seal would make a sharper point on the "victories" slide if the
author wants it back.
